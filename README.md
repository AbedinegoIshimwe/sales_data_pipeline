# Sales Data Engineering Pipeline

An end-to-end data engineering project built as part of my Week 6 Data Engineering training.

## Project Overview

The goal is to build a sales data pipeline using Python, pandas, PostgreSQL, and dbt.

The pipeline will:

1. Import and investigate raw sales data.
2. Clean missing values, duplicates, invalid numbers, and inconsistent text.
3. Transform the data by creating date-related columns and calculating revenue.
4. Load cleaned data into PostgreSQL.
5. Build staging models and an analytics mart with dbt.
6. Answer business questions using SQL.

## Technologies

- Python
- pandas
- PostgreSQL
- SQLAlchemy
- dbt
- SQL
